## 5. 试点范围建议（待领导确认）

- 建议先选 500-1000 篇高频文档（FAQ、制度、操作手册）。
- 试点目标指标：`Recall@10`、`MRR`、单次耗时、单次成本、答案引用准确率。
- 试点期间新老系统双跑，不直接替换线上服务。

## 6. 待确认问题清单

1. 旧系统负责人是谁？能否约 30 分钟介绍数据流？

3. 能否申请 embedding API 或 GPU？
4. 试点阶段能否搭建独立服务？
5. 谁负责最终验收和切换决策？
