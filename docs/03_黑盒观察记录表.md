# 黑盒观察记录表

> 目的：不读源码，通过上传文档和发起查询，推断旧系统“文档处理 + 检索 + 生成”的流水线，并记录成本、耗时和失败现象。

## 观察步骤

1. 准备 3 份测试文档：长文档（50 页以上）、含表格文档、两篇相似主题文档。
2. 上传前记录时间；上传后记录“处理完成”时间，估算文档处理耗时。
3. 分别发起 3 类查询：文档中的明确细节、同义改写、知识库中不存在的问题。
4. 每次查询记录：耗时、返回内容、是否报错、token 估算、费用估算。
5. 用 2-3 条日志或账单核对 token 与费用估算。
6. 总结推断的流水线，填入《01_摸底报告.md》。
